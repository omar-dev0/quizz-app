# Quiz App

Welcome to the **Quiz App**, a Flutter-based application that provides an interactive and engaging quiz experience. The app includes authentication features such as login, registration, and password recovery to ensure secure access for users.

## Features

### 🔐 Authentication
- **User Login** – Securely sign in with your credentials.
- **User Registration** – Create a new account to access quizzes.
- **Forgot Password** – Reset your password via email verification.

### 📚 Quizzes
- Engaging quiz questions with multiple-choice answers.
- Timed quizzes to test your knowledge under pressure.
- Score tracking to monitor progress and performance.

### 🎨 User Experience
- Responsive UI designed with Flutter for a smooth experience.
- Intuitive navigation for seamless interaction.
- Modern design with a user-friendly interface.

## 🛠️ Technologies Used
- **Flutter** – Frontend framework for cross-platform development.
- **Dart** – Programming language for app logic.
Made with ❤️ using Flutter.
